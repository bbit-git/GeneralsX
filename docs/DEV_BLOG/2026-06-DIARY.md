# Development Diary - June 2026

---

## 2026-06-01: Add zoom-correct grab panning

Added a pixel-grab camera pan path that projects pointer movement onto the
camera focus plane so desktop RMB dragging and SDL3 touch panning stay pinned
to the same world point at any zoom level.

What was done:
- added `View::scrollByPixelGrab` and the W3D implementation
- routed RMB drag scrolling through the depth-correct grab path
- updated Generals and Zero Hour SDL3 touch panning to use pixel-grab scroll

Impact:
- grab/touch panning now scales with camera height instead of using a fixed
  screen-delta distance
- legacy `scrollBy` remains available for existing edge-scroll behavior
